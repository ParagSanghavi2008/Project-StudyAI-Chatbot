# 🧠 StudyMind AI — Smart Study Assistant

**StudyMind AI** is an intelligent web application designed to help students learn faster, revise previous topics, test their knowledge with quizzes, and summarize long notes with ease.

---

## ✨ Features

- **💬 AI Study Chat**:
  - Ask any study question and get instant explanations.
  - 3 Teaching Personas:
    - **⚡ Default**: Balanced, step-by-step explanations.
    - **🎈 Friendly**: Explains like a best friend in the shortest, simplest, and fun way.
    - **🎓 Professional**: Teaches in depth like a university professor.

- **📝 Notes Summarizer**:
  - Paste lengthy textbook or lecture notes.
  - Automatically generates key points, definitions, and main takeaways.

- **🎯 Quiz Generator**:
  - Create multiple-choice quizzes on any subject with custom difficulty (Easy, Medium, Hard).
  - Instant scoring with detailed answer explanations.

- **📄 PDF Analyzer**:
  - Upload lecture PDFs or slide decks.
  - Automatically summarizes content and creates interactive practice quizzes.

- **📜 Chat & Revision History**:
  - All past study topics are saved automatically per user account.
  - Live search past topics, re-open previous chats, or export revision notes as Markdown.

- **🎨 13 Eye-Comfort Themes**:
  - **Creative**: 🌌 Cosmic Nebula, 🪸 Sunset Glow
  - **Funny & Playful**: 🍌 Banana Punch, 👾 Retro Arcade
  - **Artistic**: 🎨 Oil Canvas, 🌸 Sakura Blossom
  - **Scenery**: 🏔️ Nordic Aurora, 🏜️ Desert Canyon
  - **Classics**: 🌙 Midnight Dark, ☀️ Clean Light, 🌊 Ocean Tech, 🌲 Forest Green, 🔮 Cyber Neon

- **🔒 Secure Login & Password Protection**:
  - Sign in with Email or Mobile number.
  - Personal student data isolation for every user.
  - **Forgot Password**: Secured by verifying your registered Student Name before allowing password changes.

## 🚀 How to Run

1. **Directly in Browser**:
   - Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.

2. **Using a Local Server (Recommended)**:
   ```bash
   python3 -m http.server 3000
   ```
   Open your browser at: **http://localhost:3000**
